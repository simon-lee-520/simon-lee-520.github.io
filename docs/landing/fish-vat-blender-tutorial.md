# 鱼群 VAT 一步到位教程（Blender 中文 · 详细版）

> 目标：静态鱼 → 绑骨 → 循环游泳 → **VAT 烘焙** → 导出到本站目录。  
> 界面语言：**简体中文**。快捷键默认 **Blender 键盘映射**。  
> 推荐 Blender：**4.2 / 4.3 / 4.5 LTS**（**编辑 → 关于 Blender** 可查看版本）。

网页播放不跑骨骼；骨骼只在 Blender 里用来「做出会动的顶点」，再烤进贴图。

---

## 读教程前：先认识界面

打开 Blender 后，默认大致分区：

| 区域 | 在哪 | 干什么 |
|------|------|--------|
| **3D 视口** | 中间最大块 | 看鱼、选物体、摆姿势 |
| **大纲视图** | 右上 | 物体列表（网格 / 骨架 / 空物体） |
| **属性编辑器** | 右下 | 修改器、材质、骨架、渲染等图标页 |
| **时间轴** | 最下方 | 播放动画、设起止帧 |
| **工作区标签** | 最上方一排 | 布局 / 建模 / 雕刻 / **动画** / 着色… |

### 三种模式（左上角下拉，或快捷键）

| 模式 | 快捷键（选中物体后） | 用途 |
|------|----------------------|------|
| **物体模式** | `Tab` 切出编辑；或菜单选 | 移动整个物体、绑定、导出 |
| **编辑模式** | `Tab` | 改网格顶点 / 改骨骼形状 |
| **姿态模式** | 选中骨架后，`Ctrl+Tab` 或菜单 | **调动画姿势**（游泳关键帧在这里做） |

看不清模式时：看 3D 视口**左上角**当前显示的文字。

### 常用导航

| 操作 | 怎么做 |
|------|--------|
| 旋转视角 | 中键拖拽 |
| 平移 | `Shift` + 中键拖拽 |
| 缩放 | 滚轮 |
| 聚焦到选中物 | 选中后按 `.`（数字键盘）或 **视图 → 将所选对齐到视图** |
| 显示坐标轴 | 视口右上角小轴；红=X 绿=Y 蓝=Z |

### 打开统计信息（看三角形数量）

1. 3D 视口**右上角**点 **显示叠加**（两个圆重叠图标）旁的小箭头  
2. 勾选最下方附近的 **统计信息**  
3. 选中鱼后，视口右下角出现：顶点 / 边 / 面 / **三角形**

VAT 建议三角形大约在 **3,000～12,000**。你之前减到约 2 万也还能用，再低更好。

## 最终要交到仓库的文件

```text
source/models/landing/fish_vat/
  fish_mesh.glb       # VAT 用静态网格
  fish_pos.png        # 位置动画贴图（或插件给的主贴图改名）
  fish_nrm.png        # 法线贴图（若有单独文件）
  fish_vat.json       # 帧数、fps、贴图尺寸、min/max 等
```

若插件还生成 `remap_info.json`，**一并拷贝**进同目录，接代码时很重要。

## 第 0 步：安装 VAT 插件（先装好再往后做也行）

下面推荐两个，**装一个即可**。

### 方案 A：扩展平台「Vertex Animation Texture」（偏 Three.js 友好）

1. 打开浏览器：https://extensions.blender.org/add-ons/vat/  
2. 按页面说明获取 / 安装（Blender 4.2+ 也可用 **编辑 → 偏好设置 → 获取扩展** 搜索 `VAT` 或 `Vertex Animation`）  
3. **编辑 → 偏好设置 → 插件**，搜索 `VAT`，确认已勾选启用  
4. 回到 3D 视口，按 `N` 打开**右侧侧栏**，在 **条目 / 工具** 旁边找插件页签（常见名含 `VAT`）

烘焙后通常得到：

- 新网格 `export_mesh`
- 新 UV 名 `vertex_anim`
- 贴图 `positions`、`normals`

文档说明：若 **Normalize position** 打开，位置存成 0～1，导出 PNG 时会给出 **Min Offset / Max Offset**（必须记进 `fish_vat.json`）。

### 方案 B：OpenVAT（功能全，引擎向）

1. https://extensions.blender.org/add-ons/openvat/ 或 https://openvat.org/  
2. 同样在偏好设置里启用  
3. 面板名一般为 **OpenVAT**；主按钮类似 **Encode Vertex Animation Texture**  
4. 导出目录常见结构：

```text
某物体_vat/
  某物体.png              # 位置（或位置+打包法线）
  某物体-vnrm.png         # 单独法线（若选 Separate）
  某物体-remap_info.json  # min/max
  某物体.glb / .fbx       # proxy 网格
```

### 安装通用步骤（zip）

1. **编辑 → 偏好设置 → 插件**  
2. 右上角 **安装…**（有的版本在「获取扩展」旁）  
3. 选下载的 `.zip` → 安装  
4. 列表里勾选启用  
5. 关掉偏好设置，按 `N` 找面板  

装好后继续第 1 步；**没动画之前不要点烘焙**。

## 第 1 步：导入鱼并整理（约 10～20 分钟）

### 1.1 新建场景

1. **文件 → 新建 → 常规**  
2. 用鼠标点选中间默认立方体 → 按 `X` → **删除**  
3. 光源、摄像机可留可删，不影响

### 1.2 导入

1. **文件 → 导入 → glTF 2.0 (.glb/.gltf)**  
2. 选中 `shiny_fish.glb`（或你的源文件）→ **导入 glTF 2.0**  
3. 看右上角**大纲视图**，可能看到：

```text
Sketchfab_model          ← 空物体（三脚架图标）
  └─ xxx.fbx
      └─ RootNode
          └─ G_Fish…
              └─ G_Fish…_0.002   ← 橙色三角 = 真正的网格
```

### 1.3 只留下网格

1. 在大纲里**点选橙色三角那一行**（网格）  
2. 按 `Alt+P`（或右键）→ **清除父级并保持变换**（有的版本叫 **清空父级并保持变换结果**）  
   - 若没有此菜单：先 `Alt+P` → **清除父级**，再视情况微调位置  
3. 大纲里把上面的空物体选中删除（`X`）  
4. 确认场景里只剩 **1 条鱼网格**（统计信息「物体」最好为 1，或只多灯光）

若仍有多个网格部件：按住 `Shift` 全选网格 → `Ctrl+J` 合并。

### 1.4 检查面数

打开统计信息 → 看 **三角形**：

- **理想**：3,000～12,000  
- **可接受**：≤ 20,000  
- **太大**：加修改器 **精简 → 塌陷**，比率试 `0.3～0.5`，**应用**后再继续  

### 1.5 摆正朝向（必须统一）

本教程约定（与后续网页群游一致）：

| 部位 | 朝向 |
|------|------|
| 鼻尖 | **+X**（红轴正方向） |
| 肚皮 | **+Y**（绿轴正方向） |
| 左侧 | **+Z**（蓝轴，大致朝相机一侧时可再调） |

操作：

1. 物体模式选中鱼  
2. 视口右上角点 **变换方向**：先用 **全局**  
3. 按 `R` 旋转：  
   - `R` 再按 `X` / `Y` / `Z`：锁定绕某轴转  
   - 转的时候可看鼻尖是否沿红色箭头  
4. 也可用右侧 **条目** 面板（按 `N` → **条目**）直接改 **旋转 X/Y/Z** 度数（例如 `90`）  
5. 摆正后：**务必** `Ctrl+A` → **全部变换**  
   - 应用后，条目里位置/旋转应接近 0，缩放接近 1  

### 1.6 放到原点

1. 选中鱼  
2. `Alt+G` 清除位置（回到原点附近）  
3. 若还有偏移：条目里把位置 XYZ 手动改成 `0`  
4. 再 `Ctrl+A` → **全部变换** 一次更稳  

### 1.7 保存工程

**文件 → 保存为…** → 例如 `fish_vat_work.blend`  
后面每做完一大步就 `Ctrl+S`。

## 第 2 步：添加骨架（详细）

VAT 网页不跑骨架，但没有骨架变形，就没有可烤的游泳。

### 2.1 创建单骨

1. 确认在 **物体模式**  
2. 3D 光标在原点：`Shift+S` → **游标到世界原点**  
3. `Shift+A` → **骨架 → 单节骨骼**  
4. 大纲里会出现 `Armature`  
5. 选中骨架，右侧属性点 **物体数据属性**（小人/骨头图标），勾选 **视口显示 → 在前方**（有的叫 **在前面**），方便骨头不被鱼挡住

### 2.2 编辑模式拉出脊椎

1. 选中骨架 → 左上角切到 **编辑模式**（或 `Tab`）  
2. 你看到一根骨头：一端是根（粗），一端是尖（球）  
3. 把整根骨移到鱼身体中轴：  
   - `G` 移动，`G` 再 `Z` 只上下移等  
4. 调整第一根骨长度：选中**尖端**，`G` 沿身体拉到头后方一点（覆盖头部）  
5. 选中尖端，按 `E` **挤出**下一节，沿身体往后拉  
6. 重复挤出，直到尾尖，一共约 **5 节**：

```text
spine1（近头）→ spine2 → spine3 → spine4 → tail（尾尖）
```

7. 在大纲或右上角骨骼列表里，选中每根骨，按 `F2` 重命名（方便后面刷权重）

侧视（按数字键盘 `3` 或视图菜单 → 右视）更容易把骨排在鱼中心线上。

### 2.3 绑定：自动权重

1. 切回 **物体模式**  
2. **先点选鱼网格，再 `Shift` 点选骨架**（最后点的是活动物体，应为骨架）  
3. `Ctrl+P` → 选 **含自动权重** / **带自动权重**  
4. 成功后：大纲里鱼会成为骨架的子级；鱼上会出现 **骨架修改器**

检查修改器：选中鱼 → 右侧 **修改器属性**（扳手）→ 应看到 **骨架**，目标指向你的 Armature。

### 2.4 测试绑定是否成功

1. 只选中骨架 → 切到 **姿态模式**  
2. 点选最末节 `tail`，按 `R` 旋转  
3. **期望**：鱼尾巴网格跟着弯  
4. **若完全不动**：
   - 回到物体模式，看鱼是否有骨架修改器  
   - 是否绑错物体  
   - 撤销后重新：先网格后骨架，再 `Ctrl+P`  
5. **若头被拧烂、肚皮穿模**：进入第 2.5 节刷权重

测完后：姿态模式选中所有骨 → `A` → `Alt+R` 清除旋转，恢复休息姿态。

### 2.5 权重绘制（头少动、尾多动）

1. 物体模式**先选中鱼**  
2. 左上角模式改为 **权重绘制**  
3. 左侧工具栏选画笔；按 `N` → **工具** 可调半径、强度（强度先 `0.3～0.5`）  
4. 颜色：**红 = 权重大，蓝 = 权重小**  
5. 在右上角或顶部切换当前骨骼（要画「相对哪根骨」的权重）  
6. 典型修法：
   - 选中 `tail` / `spine4`：鱼头区域若发红，用笔画刷成蓝（或按住 `Ctrl` 减权重，视版本而定）  
   - 选中 `spine1`：头部保持一定红色，尾巴应偏蓝  

改完回物体模式，再进姿态模式拧尾骨，直到「头稳尾弯」。

`Ctrl+S` 保存。

## 第 3 步：制作循环游泳动画（最细、最重要）

这是 VAT 的**唯一内容来源**。烤出来的观感 ≈ 你在这里看到的观感。

### 3.1 切换到动画工作区（推荐）

顶部点 **动画** 工作区：下面会有时间轴 / 摄影表，方便插关键帧。

或继续用 **布局**，只要下方时间轴可见即可。

### 3.2 设置帧范围与帧率

1. 看最下方时间轴右侧或输出属性：  
   - **帧起始** = `1`  
   - **帧结束** = `40`（也可 `32`）  
2. 右侧属性 → **输出属性**（打印机图标）→ **帧率** 选 **30 FPS**（或 24，后面 json 要写同一数字）  
3. 时间轴上把绿条拖到第 1 帧

建议：先用 **40 帧 @ 30fps**（约 1.33 秒一圈）。

### 3.3 插入关键帧的正确方式

1. 选中骨架 → **姿态模式**  
2. 旋转某根骨到目标姿势  
3. **鼠标要在 3D 视口里**，按 `I`  
4. 在弹出菜单选 **旋转**（只存旋转即可；不要每次都「位置/缩放」除非你真动了）  
5. 时间轴上应出现黄色/白色关键帧菱形点  

若按 `I` 没反应：确认是姿态模式、骨头被选中、鼠标在视口内。

### 3.4 推荐姿势时间表（可照抄）

目标：**行波 S 弯**，不是整条鱼同步左右甩。

| 帧 | 做什么 |
|----|--------|
| **1** | `spine3`、`spine4`、`tail` 向**左**拧；越往后角度越大。例如尾约 20°～35°，中段约 8°～15°。`spine1` 几乎不动或向右轻微补偿 2°～5°。选中动过的骨 → `I` → 旋转 |
| **10** | 中间过渡（可自动插值，也可略调） |
| **20** | 与第 1 帧**相反**：向**右**拧，幅度相近 → 插入旋转关键帧 |
| **30** | 过渡 |
| **40** | **必须与第 1 帧姿势相同** → 插入旋转关键帧（循环接点） |

操作技巧：

- 一次选中多根骨：`Shift` 点选，再一起 `R` 旋转（再分别微调更好）  
- 旋转时按 `R` 再按轴键；或用姿态下的 **局部** 变换方向  
- 第 40 帧最快做法：时间轴选中第 1 帧所有关键帧 → `Ctrl+C` → 到第 40 帧 `Ctrl+V`（版本不同可能用「复制姿态 / 粘贴姿态」：姿态菜单里）

### 3.5 让动画更顺（插值）

1. 窗口切到 **摄影表** 或 **曲线编辑器**（动画工作区自带）  
2. 选中关键帧，插值模式用 **贝塞尔**（默认常可）  
3. 避免关键帧之间「线性硬切」导致机械感  
4. 尾骨曲线幅度可以大于中段，形成甩尾

### 3.6 循环播放检查

1. 时间轴播放按钮旁，开启 **循环** / 查看是否在起止帧之间重复  
2. 按空格播放  
3. **过关标准（必须同时满足）**：
   - 看起来像在游，而不是原地抽搐  
   - 头基本稳定  
   - 第 40 帧接到第 1 帧时**没有猛跳一下**  
4. 不过关 → 继续改姿势，**不要进入烘焙**

### 3.7（可选）把动作命名为 swim

1. 打开 **非线性动画** 或 **动作编辑器**  
2. 当前动作名称改为 `swim`  
3. 方便以后查找；VAT 烘焙一般按帧范围，不强制依赖名字  

`Ctrl+S` 保存。

## 第 4 步：烘焙 VAT（按插件分写）

烘焙前确认：

- [ ] 物体模式能播放游泳  
- [ ] 帧起始/结束正确  
- [ ] 鱼已 `全部变换`  
- [ ] 面数可接受  

### 4.A 使用「Vertex Animation Texture」扩展

1. **物体模式**选中**鱼网格**（带骨架修改器的那个）  
2. 按 `N` → 打开 VAT 面板  
3. 建议选项（名称以面板为准）：

| 选项 | 建议 |
|------|------|
| 帧范围 / Frame start-end | `1`～`40`（与时间轴一致） |
| Step | `1`（每帧都烤） |
| Position mode | 新手优先 **offset**（相对初始） |
| Normalize position | **开启**（方便导出 PNG） |
| Normals | **开启** |
| Y-flip 等 | 先默认；接 Three.js 再调 |

4. 点面板上的生成 / Bake 按钮  
5. 等待完成后检查大纲是否出现 `export_mesh`  
6. 在 **UV 编辑 / 图像编辑** 里应能看到 `positions`、`normals` 图像  

记下弹窗或控制台里的 **Min Offset / Max Offset**（XYZ 各一对，或向量），写进后面的 json。

7. （可选）按插件说明把图像 **另存为 PNG**（Non-Color / 非彩色数据）

### 4.B 使用 OpenVAT

1. 选中鱼网格（或按说明选 Collection）  
2. 打开 **OpenVAT** 面板  
3. 建议：
   - Encode target：`Active Object`  
   - Encoding：`OpenVAT Standard`  
   - Proxy：`Start Frame`（第 1 帧为基准姿势）  
   - Normals：`Separate`（单独法线贴图，好调）或 `Packed`  
   - Frame range：与时间轴一致  
   - 输出目录：选桌面空文件夹  
4. 点击 **Encode Vertex Animation Texture**（或中文等价按钮）  
5. 到输出目录确认：
   - `*.png` 主贴图  
   - `*-vnrm.png`（若 Separate）  
   - `*-remap_info.json`  
   - `*.glb` 或 `*.fbx` proxy 网格  
6. OpenVAT 常带预览集合：能播就说明编码成功  

### 4.3 烘焙失败常见原因

| 现象 | 处理 |
|------|------|
| 按钮灰 / 没反应 | 没选中网格；或插件未启用 |
| 贴图全黑/全灰 | 帧范围错；或没有顶点动画（骨架没作用到网格） |
| 预览炸模 | 轴向/编码与预览着色器不一致；先以插件预览为准 |
| 内存爆了 | 减面、减帧、Step=2 |

## 第 5 步：整理并导出到本站目录（详细）

### 5.1 创建目录

在项目里建：

```text
source/models/landing/fish_vat/
```

### 5.2 导出 / 拷贝网格

**若插件已导出 glb：**

- 把 proxy / export 的 glb **复制**为 `fish_mesh.glb` 放进上面目录  

**若只有 Blender 里的 `export_mesh`：**

1. 物体模式只选中 `export_mesh`  
2. **文件 → 导出 → glTF 2.0**  
3. 右侧：
   - 格式：**glTF 二进制 (.glb)**  
   - **限制为 → 选中的物体**  
   - 动画：可关（VAT 不需要骨骼动画轨）  
   - 尽量先**不勾 Draco**（少一层麻烦；体积大再压）  
4. 导出到 `source/models/landing/fish_vat/fish_mesh.glb`

### 5.3 贴图改名拷贝

| 插件产物（示例） | 改名为 |
|------------------|--------|
| `positions.png` / `MyFish.png` | `fish_pos.png` |
| `normals.png` / `MyFish-vnrm.png` | `fish_nrm.png` |
| `*-remap_info.json` | 保留原名或改 `remap_info.json`，放同目录 |

用 macOS「预览」打开 png，看窗口标题或检视器里的**像素宽高**。

### 5.4 手写 `fish_vat.json`

在 `fish_vat` 目录新建文本文件，内容模板：


## 附录 B：常见问题（Blender）

**Q：自动权重后拖骨完全不动？**  
A：检查修改器里目标骨架是否正确；绑定顺序是否「先网格后骨架」；是否在姿态模式改的是别的骨架。

**Q：游泳时整条鱼在扭，头也大动？**  
A：权重绘制，减掉头对尾骨的权重；关键帧里减小 `spine1` 旋转。

**Q：循环接缝会跳一下？**  
A：第 1 帧与最后一帧旋转数值必须一致；可用复制姿态粘贴。

**Q：精简后面目糊了？**  
A：比率调高（少减一点）；VAT 宁可用 1.5 万面也不要用糊成一团的 2 千面。

**Q：插件和教程按钮文字不一样？**  
A：把侧栏面板截图发我，我按你的界面改成「点哪里」对照表。

**Q：能不能用 Mixamo？**  
A：不能。Mixamo 只做人。
